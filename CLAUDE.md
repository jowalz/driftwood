# Working conventions for this repo

- **Language**: all git commit messages, code comments, and docstrings
  are written in **English**, regardless of the language used in
  conversation while building this. Conversation with the user may be
  in German; anything that lands in the repository is English. This
  includes prompt/instruction strings embedded in code (e.g. the LLM
  system prompt in `agent/agent.py`).
- `docs/CONCEPT.md` is the architecture source of truth — read it before
  making structural changes.
